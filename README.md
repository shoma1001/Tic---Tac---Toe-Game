# Tic---Tac---Toe-Game

A simple two-player Tic Tac Toe game built with Python.

## How to Run

```bash
python tictactoe.py
```

## How to Play
- Two players take turns: **X** and **O**
- Enter a number (1–9) to place your mark
- First to get 3 in a row (horizontal, vertical, or diagonal) wins!

## Requirements
- Python 3.x
